💡 How to use this

At the end of any Claude chat, ask: "Give me a session summary using the standard template." Then either paste the whole block into Smart Paste below (it auto-fills everything), or use the flexible form.

⚡ Smart Paste (recommended)

Paste a full template-formatted summary here. PROJECT, DATE, SESSION TITLE, and content will auto-fill below — and any files listed in the FILES / LINKS section will be automatically attached to the project when you save. 📎

Standard Summary Template

Copy this prompt and paste it at the end of any Claude session. Claude will fill it in.

📋 Copy this prompt and send it to Claude at the end of a session:

Please give me a session summary in this exact format so I can paste it into my Project Tracker: PROJECT: [which of my projects this relates to] DATE: [today's date] SESSION TITLE: [short descriptive title] WHAT WE DID: - [bullet point of accomplishments] - [bullet point] DECISIONS MADE: - [any key decisions or directions chosen] OPEN QUESTIONS / BLOCKERS: - [anything unresolved] NEXT STEPS: - [what to tackle next session] - [follow-up items] FILES / LINKS: - Label | path or URL | short description - Label | path or URL | short description (One file per line. Use the pipe character | to separate the three fields. Include every file we created or referenced, with the full path or URL.) CONTEXT TO REMEMBER: - [important context for picking this up next time]

🎯 Why use the template?

Consistent summaries make it much easier to pick up a project weeks later. The "Context to Remember" section is especially useful — it preserves the why and the state-of-mind, not just the what.

Save / Load Your Data

Data auto-saves to this browser. Export a backup file to keep it safe or move between computers.

💾 Backup (Export)

Download all your projects, notes, and summaries as a JSON file. Save it somewhere safe.

📂 Restore (Import)

Load a previously-exported backup file. Pick the right behavior:

🔀 Merge (recommended)
Adds new projects, summaries, attachments, sub-tasks, and links from the file without deleting anything you already have. Safe to run anytime.
📁 Replace (full restore)
Erases all current data and replaces it with the contents of the file. Use this only when restoring a snapshot to an empty tracker.

⏱️ Restore Points

Automatic snapshots taken before any replace, reset, merge or delete. The last 12 are kept.

🔄 Reset to Starter Projects

Replace all data with the original starter project list (from your uploaded doc).
